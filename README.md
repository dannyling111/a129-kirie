# KIRIE 漫画工坊

A129 独立仓库网页：量化立绘城市漫画。人物是日式 RPG 大半身，底边锁在画面下沿；对话面对面；同框同一身高。

## 线上地址

- 首页：https://dannyling111.github.io/a129-kirie/
- 仓库：https://github.com/dannyling111/a129-kirie

纯静态页，打开即可。自己的稿存在浏览器本地。

## 里面有什么

- 8 篇城市漫画样板（末班电车、便利店、天台、雨巷、加班、绿灯、窗边、第一班）
- 工坊：拖图层、对白、翻转朝向
- 量化引擎：90×120 格、六层景深、朝向规则

## 本地

```sh
npm install
npm run dev
```

GitHub Pages 构建：

```sh
npm run build:pages
```

`dist/` 就是发布目录。
